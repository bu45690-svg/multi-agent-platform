# System Design Concepts

## Microservices
Microservices architecture splits applications into small independent services.
Each service handles a specific business function and communicates via APIs.

## Message Queues
Message queues enable asynchronous communication between services.
They improve reliability and decouple producers from consumers.

## Databases
PostgreSQL is a powerful relational database with JSONB support.
FAISS is a library for efficient similarity search on dense vectors.
